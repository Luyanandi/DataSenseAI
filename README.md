# DataSenseAI 

An AI-powered Business Intelligence platform that transforms raw business data into meaningful insights through analytics, machine learning, and natural language AI.

---

## Features

- Upload Excel & CSV datasets
- Automatic data cleaning
- Interactive dashboards
- Business KPI analysis
- AI-generated insights
- Sales forecasting
- Ask your data using natural language
- Report generation

---

## Tech Stack

### Backend
- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- Pandas

### Frontend
- React
- Chart.js / Plotly

### AI & Machine Learning
- OpenAI / Gemini API
- Scikit-learn
